# Zohar · זוהר לפרשת השבוע

[Öffentliche EN/HE-Leseseite](https://moriahise.github.io/Zohar/)

Wöchentliche Zohar-Lektüre zur israelischen Wochenparasha, ab Mittwoch für den kommenden Shabbat. Dieses Repository enthält ausschließlich den öffentlichen Leserexport.
